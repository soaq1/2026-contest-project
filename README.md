\# 데이터 수집 히스토리



2026년 물류데이터·AI 활용 및 분석 아이디어 공모전 (대전정보문화산업진흥원) 참가 프로젝트

데이터 수집 과정 기록 — 서식3(분석과정보고서) 작성용



\## 1. 도로망 뼈대

\- \*\*OSM 대전 도로망\*\*: OpenStreetMap, osmnx로 코드에서 직접 추출 (승인 불필요)



\## 2. 물류시설 현황

\- \*\*출처\*\*: 국토교통 통계누리 (stat.molit.go.kr)

\- \*\*파일\*\*: `logistics\_terminal\_status.csv`

\- \*\*비고\*\*: 공고문엔 "국토교통부(물류데이터)"로만 표기돼 있었으나, 실제 등록명은 "일반물류터미널 현황"이었음. 공고문 표기와 실제 데이터셋명이 다른 경우가 많아 발간기관명을 바꿔가며 재검색 필요했음.



\## 3. 화물차 통행실태 → 화물 O/D 데이터로 대체

\- \*\*최초 시도\*\*: 공고문에 안내된 KL-Net 물류정보포털 (www.klnet.co.kr)

\- \*\*문제\*\*: KL-Net은 무역·통관 EDI 서비스(AFR, ICS2, AMS 등) 중심이며, 가입 시 사업자등록증 제출이 필요해 개인/학생 참가자는 접근 불가로 판단, 이용 포기

\- \*\*대체 경로\*\*: 국가교통DB(KTDB, ktdb.go.kr) → 정보공개 > 자료신청 → 사용목적 작성 후 승인 없이 즉시 다운로드

\- \*\*최종 데이터\*\*: 전국지역간 톤급별 화물자동차 통행량 OD(2023년 기준), 전국지역간 품목별 도로물동량 OD(2023년 기준) — 지역 필터 없이 전국 단위로 받아 대전 관련 O/D만 추후 로컬 필터링 예정

\- \*\*파일\*\*: `ton\_class\_freight\_od.zip`, `commodity\_road\_freight\_od.zip`

\- \*\*제외한 것\*\*: 기종점통행량\_여객(14종, 물류와 무관), 철도항공 수단별 물동량(도로망 그래프 범위 밖)



\## 4. 한국도로공사 (data.ex.co.kr)

\- \*\*인증키\*\*: 발급 즉시 자동승인 (활용기간 별도 확인 필요)

\- \*\*trafficRegion(권역별 소통정보)\*\*: 정상 작동하나 권역 단위 집계라 그래프 간선 가중치로 부적합 → 미사용 결정

\- \*\*vdsList(VDS 설치정보)\*\*: 정상 작동, 전국 8,461개 지점 확인. 좌표가 GRS80 좌표계라 OSM(WGS84)와 결합 시 pyproj로 좌표변환 필요

\- \*\*sectionTrafficRouteDirection(구간교통량)\*\*: 날짜/시간/콘존ID 등 다양한 파라미터 조합 시도했으나 계속 0건 반환. 원인 미확인 상태로 한국도로공사 고객센터(054-811-4418) 문의 예정

\- \*\*대체 확보\*\*: data.go.kr 파일데이터 "한국도로공사\_지점 교통량"을 직접 다운로드하여 대체 (`vds\_point\_traffic\_5min\_20260716.csv`) — VDS\_ID 기준으로 VDS 설치정보와 조인 가능



\## 5. 기상청 API허브

\- \*\*인증키\*\*: 이메일 가입 + 휴대전화 SMS 인증 후 발급, 즉시 사용 가능

\- \*\*시행착오\*\*: 인증키가 유효해도 API별로 \*\*활용신청\*\*을 따로 해야 함 (미신청 시 403). 잘못된 키는 401이 반환되므로 401/403으로 키 문제인지 신청 문제인지 구분 가능

\- \*\*최종 사용\*\*: 지상 및 AWS 일통계 (`sfc\_aws\_day.php`) — 활용신청 승인 후 수집 완료. 문서(help=1)가 부실해 파라미터를 실측으로 확정: tm1/tm2는 YYYYMMDD만 인식, obs는 ta\_max/ta\_min/rn\_day/ws\_max 4종만 작동, 응답은 EUC-KR 텍스트

\- \*\*수집 결과\*\*: 대전권 5지점(대전 ASOS, 정림, 오월드, 세천, 장동) × 4개 통계 × 2023-01-01\~2026-07-17 = 24,619건 (`kma\_observations.json`). 정림은 2023-11-03 신설이라 이전 데이터 없음

\- \*\*미완\*\*: 동네예보 통보문 조회는 활용신청 미승인 상태(403)로 보류



\## 6. 한국에너지공단 — 수송부문 에너지사용 및 온실가스배출량 통계

\- \*\*시행착오\*\*: 공고문의 "환경부 배출량 통계"로 검색했으나 결과 없음 → 실제로는 환경부가 아니라 한국에너지공단이 발간·등록한 데이터였음. 또한 "산업부문"과 "수송부문"이 이름이 유사해 처음에 잘못된 부문을 찾기도 했음

\- \*\*인증키\*\*: 활용신청 즉시 자동승인, 활용기간 2026-07-17 \~ 2028-07-17

\- \*\*End Point\*\*: `https://apis.data.go.kr/B553530/GHG\_LIST\_02`

\- \*\*사용 항목\*\*: 수송부문-운수업 에너지사용량 통계(전체), 수송부문-운수업 에너지사용량(업종별) 통계

\- \*\*비고\*\*: 에너지사용량 통계이지 배출계수가 아니므로, 온실가스종합정보센터(GIR, gir.go.kr)의 국가 배출계수표와 결합해 CO2 환산 필요



\## 7. 미완료

\- 대전 각 구 데이터포털(유성/서구/동구·대덕구) 교통량·교통사고 데이터

\- 대전 트램 2호선 공사구간 좌표 (수작업 조사)

\- 폐점 매장(홈플러스·세이백화점) 위치 (수작업 조사)

\- 검증용 통계 (KOSIS 등, 결과 산출 후 진행)
